# SmartStore — النسخة المعدّلة

واجهة أمامية باللغة العربية، تحفظ البيانات محليًا في المتصفح.

## التشغيل
من داخل مجلد SmartStore شغّل:

```sh
python3 -m http.server 8080
```

افتح عنوان الخادم في المتصفح. لا تفتح index.html مباشرة لأن تحميل الصفحات يستخدم fetch ووحدات JavaScript.

## التعديلات
- توسيط تسميات الحقول والنصوص والقوائم.
- إشعارات المخزون الفعلية، عدّاد غير المقروء، حفظ حالة القراءة، والانتقال إلى المخزون.
- شعار SVG محلي في التبويب وفي واجهة التطبيق.
- إصلاح قائمة الموبايل وتنسيق النموذج والجدول ومطابقة أعمدته.
- تحسين التركيز بلوحة المفاتيح وإغلاق الإشعارات بزر Escape.

الأيقونات العامة تستخدم Font Awesome من CDN وتحتاج اتصالًا بالإنترنت؛ شعار المتجر والجرس وزر قائمة الموبايل محلية.
تسجيل الدخول تجريبي محلي، ولا يوجد خادم أو نظام مصادقة إنتاجي.
