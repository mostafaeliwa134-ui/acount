# SmartStore Complete / 05

نسخة مستقلة للتنزيل، دون استبدال ملفات SmartStore الأصلية في جذر المستودع.

[تحميل ZIP مباشرة](https://raw.githubusercontent.com/mostafaeliwa134-ui/acount/main/downloads/smartstore-complete-v5/SmartStore-Complete-v5.zip)

فك الضغط وافتح **SmartStore-Complete.html** بمتصفح كامل مثل Chrome أو Edge، وليس نافذة معاينة الملفات داخل تطبيق الرسائل. المشروع وقائمة التغييرات وتقرير الفحص والاختبارات موجودة داخل ZIP.

## الأقسام المفعلة
الزباين، الموردون، المشتريات المرتبطة بالمخزون، الديون والتحصيل، المصروفات، الموظفون والإعدادات.

الحفظ محلي في نفس المتصفح والعنوان. لم يُربط Laravel بهذه النسخة. تغيير العنوان أو المتصفح قد يغيّر مساحة التخزين المتاحة، ولا ينقل ZIP بيانات حسابك من جهاز آخر. بيانات الموظفين ليست حسابات دخول أو صلاحيات.
