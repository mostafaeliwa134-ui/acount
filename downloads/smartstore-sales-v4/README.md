# SmartStore Sales / 04

نسخة مستقلة للتنزيل، دون استبدال ملفات SmartStore الأصلية في جذر المستودع.

## التنزيل

[تنزيل المشروع ZIP](https://github.com/mostafaeliwa134-ui/acount/raw/refs/heads/main/downloads/smartstore-sales-v4/SmartStore-Sales-v4.zip)

فك الضغط وافتح **SmartStore-Sales.html** في متصفح مثل Chrome أو Edge. افتح الملف في المتصفح نفسه، وليس نافذة معاينة الملفات داخل تطبيق الرسائل. يحتوي ZIP أيضًا على ملفات المصدر وقائمة التغييرات وتقرير الفحص.

- ألوان كحلية وزرقاء وسماوية، وشاشة دخول جانبية للكمبيوتر وبانر مختصر للموبايل.
- معالجة فشل تحميل JavaScript وحالات التخزين والجلسة وكلمة المرور.
- البحث بالمنتجات والفواتير، التصفية، CSV، المخططات وتنبيهات المخزون والملف الشخصي.
- الحسابات محلية في نفس المتصفح والعنوان؛ ظهور حساب غير موجود في عنوان جديد لا يعني حذف بيانات النسخة السابقة. لا يتم نقل البيانات بين الأجهزة تلقائيًا.
- بعض أقسام الإدارة غير مكتملة وتظهر مميزة بوضوح؛ لا توجد خدمة باك إند أو استعادة بالبريد.
